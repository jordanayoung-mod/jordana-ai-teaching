Accessibility

Accessibility statement

I want this website to work for the widest range of people. It is built to meet Israeli Standard 5568, which is based on the Web Content Accessibility Guidelines (WCAG) 2.0 Level AA, and the Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 2013.

Statement date: 20 November 2026. This statement should be re-checked if counsel or an accessibility audit asks for changes.

What I have done

  • Pages use headings, lists, and buttons in HTML, so they work with a keyboard and with common screen readers.
  • Forms have visible labels, text errors, and a way to skip to the content.
  • Colour contrast for text meets AA on the colours used here. Information is not given by colour alone.
  • Text can be resized. The layout is built for a phone first.
  • Motion is reduced when your device asks for that.
  • The site is in English, and the language is marked in the page.

Limits I know about

Payment, booking, and the form host run on other companies' websites once they are connected. I pick providers that aim to be accessible, and I don't control their pages. If one of those pages blocks you, contact me and I'll take the booking or the form another way.
